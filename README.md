# موقع دالين تكس — للمفروشات وبدائل السجاد

موقع تعريفي مفتوح المصدر لمصنع **دالين تكس**، مبني من كتالوج المنتجات 2026.
مكتوب بـ HTML و CSS و JavaScript فقط، بدون أي إطار عمل أو خادم أو قاعدة بيانات، فيعمل على أي استضافة مجانية.

## المحتوى

- واجهة رئيسية، ونبذة عن المصنع، والمميزات
- 6 خطوط إنتاج: جوبلان 3D، جوبلان 7D، مشايات، فرو جاكار، كسوة إنتريه جاكار، كسوة إنتريه قطيفة
- لكل منتج: الصور، والمواصفات، وجدول المقاسات أو الأطقم، ومعرض تصميمات بأرقام
- نموذج طلب يجهّز رسالة واتساب جاهزة للعميل
- زر واتساب عائم، ورقم الهاتف، وكود QR لصفحة الفيسبوك
- متوافق مع الموبايل، وباللغة العربية (من اليمين لليسار)

## تشغيله على الكمبيوتر

افتح ملف `index.html` بالمتصفح مباشرة، لا يحتاج أي تثبيت.

## التعديل

كل البيانات في ملف واحد: **`assets/js/data.js`**

| ماذا تريد؟ | ماذا تعدّل في `data.js` |
|---|---|
| تغيير رقم الهاتف أو واتساب | `phone` و `whatsapp` (واتساب بالصيغة الدولية: `2011...`) |
| إظهار زر الفيسبوك | ضع الرابط في `facebook` |
| إضافة تصميم للمعرض | ضع الصورة في `assets/img/` وأضف اسمها لقائمة `gallery` |
| تعديل المقاسات | قائمة `sizes` أو `sets` للمنتج |
| إضافة منتج جديد | انسخ أي منتج داخل `PRODUCTS` وعدّل بياناته |

الألوان والخطوط في أول ملف `assets/css/style.css`.

## النشر مجانًا على GitHub Pages

1. أنشئ مستودعًا جديدًا على [GitHub](https://github.com/new) باسم مثل `dalin-tex`.
2. ارفع كل محتويات هذا المجلد إليه (زر **Add file → Upload files**).
3. من **Settings → Pages** اختر الفرع `main` والمجلد `/ (root)` ثم **Save**.
4. بعد دقيقة يصبح الموقع متاحًا على `https://اسم-المستخدم.github.io/dalin-tex/`.

يمكن أيضًا سحب المجلد وإفلاته في [Netlify Drop](https://app.netlify.com/drop) أو رفعه على Cloudflare Pages. ولربط دومين خاص (مثل `dalintex.com`) أضفه من إعدادات الاستضافة.

## هيكل الملفات

```
index.html            الصفحة الرئيسية
assets/css/style.css  التنسيق
assets/js/data.js     بيانات المصنع والمنتجات (عدّل هنا)
assets/js/main.js     عرض المنتجات، نموذج الطلب، عارض الصور
assets/img/           الشعار وصور المنتجات
```
